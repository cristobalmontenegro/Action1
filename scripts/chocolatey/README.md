# 🍫 Chocolatey

[Español abajo](#chocolatey-1)

**🇬🇧 English**

Category-level index for the **Chocolatey** scripts. One keeps Chocolatey-managed software up to date, the other reports whether Chocolatey itself is installed. Together they let you manage Chocolatey as a "software that manages software" stack from Action1.

| Script | What it does | Reads / writes | Schedule? |
| :--- | :--- | :--- | :---: |
| [**Action-ChocolateyUpgradeAll**](./Action-ChocolateyUpgradeAll) | Silently upgrades every Chocolatey-managed package with `choco upgrade all -y`. | — | Recommended monthly |
| [**Set-CustomAttribute-Chocolatey**](./Set-CustomAttribute-Chocolatey) | Reports whether Chocolatey is installed as the custom attribute `Chocolatey` (1/0). | `Chocolatey` (1/0) | Recommended weekly |
