# 🚀 Boot

[Español abajo](#arranque)

**🇬🇧 English**

Category-level index for the **boot** scripts. These scripts change the Windows **Boot Configuration Data (BCD)** — they are powerful and can leave a machine in an unexpected state if not reverted, so each README includes an explicit "how to revert" note where applicable.

| Script | What it does | Reboots? | Persistent? |
| :--- | :--- | :---: | :---: |
| [**Set-SafeModeBoot**](./Set-SafeModeBoot) | Forces the next boot into **Safe Mode with networking** and reboots in 5 seconds. | **Yes** | **Yes** (until reverted) |
| [**Enable-LegacyBootMenu**](./Enable-LegacyBootMenu) | Re-enables the classic **F8 boot menu** so you can enter recovery options on startup. | No | No |

# 🚀 Arranque

**🇪🇸 Español**

Índice de la categoría **boot**. Estos scripts modifican la **BCD (Boot Configuration Data)** de Windows — son potentes y pueden dejar el equipo en un estado inesperado si no se revierten, así que cada README incluye una nota explícita de "cómo revertir" cuando aplica.

| Script | Qué hace | ¿Reinicia? | ¿Persistente? |
| :--- | :--- | :---: | :---: |
| [**Set-SafeModeBoot**](./Set-SafeModeBoot) | Fuerza el siguiente arranque en **Modo Seguro con red** y reinicia en 5 segundos. | **Sí** | **Sí** (hasta revertir) |
| [**Enable-LegacyBootMenu**](./Enable-LegacyBootMenu) | Reactiva el **menú F8 clásico** para acceder a opciones de recuperación al arrancar. | No | No |
